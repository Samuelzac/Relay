How it works
Castlink gives hosts a private livestreaming checkout, a broadcaster page, and a viewer watch page without requiring viewer accounts. Use HLS for larger audiences, WebRTC for fast low-latency streams, or both when an event needs flexibility.
Create an event, pay, then you'll receive:
  • Private broadcast link (for the host)
  • Public watch link (for viewers)
After purchase you receive browser links and OBS setup details by email.

FAQ
Do viewers need to log in?

No. Anyone with the watch link can view (subject to the concurrent viewer limit).

Do I need an app to broadcast?

No app install. Broadcasting is done in a mobile browser via a private broadcast link.

Is the stream recorded?

Not in this MVP. Castlink is focused on simple live delivery. Recording can be added later.

What content is allowed?

Hosts are responsible for content. See the Terms for prohibited content and enforcement.
