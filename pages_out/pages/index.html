How it works
Castlink gives hosts a checkout, a private broadcaster page, and a viewer watch page. Choose low-latency live for the shortest delay, recorded stream for a slightly delayed viewer link with MP4 recording, or both when an event needs flexibility.
Create an event, pay, then you'll receive:
  • Private broadcast link (for the host)
  • Public watch link (for viewers)
After purchase you receive the event links by email. The main broadcast path works directly in a phone browser, with OBS available for compatible events.

FAQ
Do viewers need to log in?

No. Anyone with the watch link can view, subject to the event viewer limit.

Do I need an app to broadcast?

No. The main host workflow runs in a mobile browser through a private broadcast link.

Is the stream recorded?

Not in this MVP. Castlink is focused on simple live delivery. Recording can be added later.

What content is allowed?

Hosts are responsible for content. See the Terms for prohibited content and enforcement.
